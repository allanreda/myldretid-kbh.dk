ℹ️ Om denne visualisering

Forudsigelserne opdateres flere gange dagligt og viser procentvise afvigelser i rejsetid sammenlignet med det normale. Grøn betyder hurtigere trafik end normalt, rød betyder langsommere.

Kilde: Egne modeller baseret på data fra København og vejrprognoser. Hosting og datalagring via Google Cloud Platform.
